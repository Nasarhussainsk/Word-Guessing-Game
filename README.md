# Word-Guessing-Game
A simple \*\*Word Guessing Game built with Python\*\* using a Jupyter Notebook. The player tries to guess a randomly selected word by entering one letter at a time.

**Project Overview**
The game randomly selects a word from a predefined list and gives the player \*\*6 attempts\*\* to guess the word.

The project demonstrates basic Python programming concepts such as:
 * Variables and data types
 * Lists
 * Random selection
 * `while` loops
 * `if-else` conditions
 * User input
 * String manipulation
 * Input validation
 * Exception handling



**How the Game Works**



1\. The game selects a random word.

2\. The word is hidden from the player.

3\. The player enters one letter at a time.

4\. Correctly guessed letters are revealed.

5\. Repeated letters are not accepted.

6\. The player has \*\*6 attempts\*\*.

7\. The game ends when:



\* The player successfully guesses the word, or
\* All attempts are used.

2\. Open the project folder.

